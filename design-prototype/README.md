# Respaw full-app HTML prototype

Open `index.html` in a browser. The left review panel lists all 57 product surfaces; on narrow screens, use the app's own navigation and connected flow actions.

## Main review flows

- `#/home` — Home and daily care
- `#/find-care` — Search → vet profile → booking
- `#/booking-pet` — Four-step booking → payment → confirmation
- `#/appointments` — Appointments → detail → consultation
- `#/pets` — Pets → health timeline → medications/reminders
- `#/profile` — Profile → payments, plans, preferences, support
- `#/emergency` — Emergency entry → SOS tracker

This is a design prototype. It uses realistic local state and simulated outcomes; it does not call production APIs or complete real medical, payment, emergency, or account actions.
